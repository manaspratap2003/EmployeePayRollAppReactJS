# EmployeePayRollAppReactJS

A React JS Employee Payroll Application developed as part of BridgeLabz training.

## Author
Manas (smanaspratap)

## Features
- Hello World React Setup
- Payroll Form to Add Employee
- Employee Service with Axios
- JSON Server Integration
- Success/Error Response Handling
- Home Page: Display All Employees
- Update Employee
- Delete Employee
- Spring Boot Integration
- Employee Profile Image Upload

## Setup
npm install
npm start
